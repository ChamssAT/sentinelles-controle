Connexion

Collez votre jeton GitHub pour pouvoir modifier l'état du jeu. Il reste dans ce navigateur uniquement.

Créer un jeton (une seule fois)
  1. Ouvrir github.com → Fine-grained token.
  2. Nom : « Poste de commandement », expiration au choix (1 an).
  3. Repository access : Only select repositories → sentinelles-controle.
  4. Permissions → Repository → Contents : Read and write.
  5. Générer, copier le jeton et le coller ici.
